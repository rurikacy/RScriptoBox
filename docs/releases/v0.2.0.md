## 🇨🇳 中文

**RScriptoBox v0.2.0 — Windows 脚本工作台**

首个公开版本。使用 Rust、Tauri 2 与 Vue 3 构建，面向 Windows x64，集中管理 CMD / BAT、PowerShell 与 Python 脚本。

### 功能

- 脚本导入与拖放，支持搜索、分类、标签、收藏、卡片和列表视图。
- 导入时创建工作台副本，后续运行和编辑使用副本，删除原入口文件后仍可使用。
- 为脚本绑定明确的解释器，配置参数、工作目录、环境变量、超时和成功退出码。
- ConPTY + xterm.js 内置交互终端，支持 `input()`、`Read-Host`、`pause`、Ctrl+C 和终端尺寸调整；也可使用系统控制台。
- 环境检测与手动登记，查看安装计划后准备 Python / PowerShell 7；支持 Python venv 与 requirements.txt 依赖安装。
- 实时输出、任务停止、运行历史、日志回放与导出。
- 暗色紫色界面，紧凑布局，默认 16px 正文和可调字号，支持 DPI 缩放。

### 下载与首次运行

1. 下载 **RScriptoBox-0.2.0-windows-x64-portable.zip**，完整解压到可写的本地目录。
2. 确认已安装 [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
3. 保留 `portable.flag`，双击 `RScriptoBox.exe`。
4. 在“环境中心”检测或准备解释器，然后添加脚本、配置环境并运行。

**发布包不捆绑 WebView2、Python 或 PowerShell 7；运行应用不需要 Rust 或 Node.js。** CMD 与 Windows PowerShell 5.1 是系统组件，仅检测、不替换。安装可能受网络、UAC 和企业策略影响。

附带 **RScriptoBox-0.2.0-source.zip** 与 **SHA256SUMS.txt**。可导入 `examples/interactive.*` 检查交互体验。详细说明见 [中文 README](https://github.com/rurikacy/RScriptoBox/blob/v0.2.0/README.md)。

### 升级与迁移

- 从早期本地版本升级：退出并备份整个旧目录，将新 EXE 替换到原位置，保留 `data` 和 `portable.flag`。
- 数据库升级到 schema 2 前自动备份；仍可访问的旧脚本会复制到工作台，源文件缺失或复制失败时需要重新导入。
- 换设备需复制整个便携目录，重新检测并绑定解释器、重建 Python venv。只复制入口脚本，关联资源需自行放入副本目录。
- 数据库备份不包含脚本文件；回退旧程序需恢复升级前的完整目录备份。

### 验证与限制

- 已有本地验证：Rust **40 项通过、1 项压力测试默认跳过**；Windows 原生执行套件 **12 项通过**；前端 **8 项通过**。
- 验证覆盖中文交互输入、PowerShell Read-Host / ReadKey、CMD set /p / pause、Ctrl+C、任务停止、脚本副本与目录迁移；TypeScript / Vite、Clippy 与格式检查通过。
- 目标为 Windows 10 22H2 / Windows 11 x64；本地实测 Windows 10，未完成 Win11 实机与完整安装矩阵验收。
- 程序未签名。脚本按应用权限执行，**不是沙箱**；请仅运行可信脚本。
- CMD 特殊字符采用保守校验，部分路径与参数会被拒绝。终端日志可能包含输入回显，密码是否隐藏取决于脚本的输入方式。
- 详细范围见 [验证记录](https://github.com/rurikacy/RScriptoBox/blob/v0.2.0/docs/verification.md)；GitHub CI 状态以实际运行记录为准。

## 🇬🇧 English

**RScriptoBox v0.2.0 — Windows Script Workspace**

The first public release, built with Rust, Tauri 2 and Vue 3 for Windows x64. Manage CMD / BAT, PowerShell and Python scripts in one workspace.

### Features

- File and drag-and-drop import, search, categories, tags, favorites, and card/list views.
- Workspace copies used for execution and editing, surviving deletion of the original entry script.
- Explicit interpreter bindings, arguments, working directories, environment variables, timeouts and success exit codes.
- Interactive ConPTY + xterm.js terminal supporting `input()`, `Read-Host`, `pause`, Ctrl+C and resizing; a system console is also available.
- Runtime detection and registration, reviewed Python / PowerShell 7 installation plans, Python venvs and requirements.txt dependency installation.
- Live output, task termination, run history, log replay and export.
- Compact dark purple interface with default 16px body text, adjustable font sizes and DPI scaling. The application UI is currently Simplified Chinese; documentation is bilingual.

### Download and First Launch

1. Download **RScriptoBox-0.2.0-windows-x64-portable.zip** and extract it completely into a writable local directory.
2. Ensure [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) is installed.
3. Keep `portable.flag` and launch `RScriptoBox.exe`.
4. Detect or prepare interpreters in Runtime center, then import, configure and run a script.

**WebView2, Python and PowerShell 7 are not bundled. Running the application does not require Rust or Node.js.** CMD and Windows PowerShell 5.1 are detected system components and are not replaced. Network access, UAC and enterprise policy can affect installation.

Also included: **RScriptoBox-0.2.0-source.zip** and **SHA256SUMS.txt**. Try `examples/interactive.*` for interactive input. See the [English README](https://github.com/rurikacy/RScriptoBox/blob/v0.2.0/README_EN.md).

### Upgrading and Moving

- To upgrade an earlier local version, exit and back up its entire directory. Replace the EXE in place, keeping `data` and `portable.flag`.
- A database backup precedes the schema 2 upgrade. Accessible legacy entry scripts are copied into the workspace; missing originals or failed copies require reimporting.
- Copy the entire portable directory to move devices, detect and bind interpreters again, and recreate Python venvs. Only entry scripts are copied automatically; add associated resources to their workspace folders.
- Database backups do not include script files. Reverting requires the complete pre-upgrade directory backup.

### Validation and Limitations

- Existing local results: **40 Rust tests passed, 1 stress test skipped by default**; **12 native Windows tests passed**; **8 frontend tests passed**.
- Coverage includes Unicode input, PowerShell Read-Host / ReadKey, CMD set /p / pause, Ctrl+C, task termination, script copies and directory migration. TypeScript / Vite, Clippy and formatting checks passed.
- Targets Windows 10 22H2 / Windows 11 x64. Local testing used Windows 10; Windows 11 and the complete installation matrix have not been validated.
- The executable is unsigned. Scripts inherit application privileges; **this is not a sandbox**. Run trusted scripts only.
- Conservative CMD validation rejects some special characters in paths and arguments. Terminal logs may contain input echo; password hiding depends on the script's input method.
- See the [validation record](https://github.com/rurikacy/RScriptoBox/blob/v0.2.0/docs/verification.md) for scope. GitHub CI status is reported separately by actual workflow runs.
